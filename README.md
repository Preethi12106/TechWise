# TechWise: AI-Powered Software Engineering Decision Agent

TechWise is an AI-powered software engineering decision assistant that helps development teams **record, retrieve, and evaluate technology and architecture decisions**.

Teams often remember what technology they selected but forget why they selected it. TechWise solves this by maintaining persistent decision memory and using an LLM to reason about previous decisions when project requirements change.

---

## 🚀 Features

### 🧠 Decision Memory

Record important software engineering decisions along with:

- Technology or decision
- Project context
- Reason for choosing it
- Alternatives considered
- Expected consequences

Decisions are stored persistently using SQLite.

### 🔎 Decision Retrieval

Search previously recorded decisions using keywords.

TechWise can retrieve information such as:

- What technology was selected?
- Why was it selected?
- What alternatives were considered?
- What were the expected consequences?

### ⚡ Decision Impact Analysis

When a project requirement changes, TechWise can evaluate whether an existing decision is still appropriate.

The agent provides one of three recommendations:

- **KEEP** – The original decision still fits.
- **RECONSIDER** – The decision may still work, but alternatives should be evaluated.
- **REPLACE** – The original decision no longer fits the new requirement.

The final recommendation is generated by the LLM based on the stored decision and the new requirement.
